
# Personal portfolio skeleton

## Run locally

```sh
npm install
npm run dev
```

Run `npm run lint` and `npm run build` to validate the project.

## Edit the portfolio

Update all site copy, timeline entries, project details, image paths, social links, and handles in [`src/data/content.js`](./src/data/content.js). The default images use [`public/placeholder.svg`](./public/placeholder.svg); replace the paths in the content file when you add your own images.
